## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Qué construir

Este proyecto es una landing estática de catálogo para La Vendimia. **Antes de escribir código, lee [`docs/LANDING.md`](docs/LANDING.md)**: define el alcance, el diseño, la estructura de la página, el manejo de imágenes, el modelo de datos y los criterios de aceptación. Los datos del catálogo y las imágenes de ejemplo ya están en `src/data/` y `src/assets/`.
